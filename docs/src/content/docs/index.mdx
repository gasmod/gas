## What is Gas?

Gas is a modular Go framework for building SaaS backends. It provides
dependency injection, routing, middleware, events, and service lifecycle so
each application starts with working infrastructure and a clear structure.

The framework has a small core package, `github.com/gasmod/gas`, and optional
modules for databases, configuration, authentication, storage, email, queues,
and more. Each module is its own Go module, so applications only add the
dependencies they use.

Use the sidebar to browse topics, or search with `Ctrl+K` / `⌘K` to find a
specific API or behavior.

## Start a new app

Add the core package to your Go module:

```sh
go get github.com/gasmod/gas
```
