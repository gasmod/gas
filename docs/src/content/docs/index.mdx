Gas is a modular Go framework for SaaS backends. The core gives you
dependency injection, routing, middleware, events and a service lifecycle.
Everything else is an optional module, each its own Go module, so your app
only pulls in what it uses.

## A complete app

```go
package main

import (
	"context"
	"log"
	"net/http"

	"github.com/gasmod/gas"
)

func main() {
	app := gas.NewApp()

	app.Router().Handle(nil, http.MethodGet, "/", func(ctx gas.Context) error {
		return ctx.Text(http.StatusOK, "Hello, World!")
	})

	if err := app.Run(context.Background()); err != nil {
		log.Fatal(err)
	}
}
```

`go run .` starts a server on port 8080. Ctrl+C shuts it down gracefully.
