`gas/storage` defines two interfaces, `storage.Provider` for buckets and
objects and `storage.Presigner` for presigned URLs. It implements them on AWS
S3 and S3-compatible services (`storage/s3`) and on a local directory
(`storage/dir`, a `Provider` only). Your services depend on the interfaces, so
the same code runs against a directory or LocalStack in development and S3 in
production.

```bash
go get github.com/gasmod/gas/storage
```

## Operations

Every method takes an input struct. `BaseObjectInput` carries the `Key` and an
optional `Bucket`; a nil `Bucket` means the configured default bucket.

| Method | Returns | Notes |
|---|---|---|
| `CreateBucket(ctx, *CreateBucketInput)` | `*Bucket` | A bucket you already own is success |
| `HeadBucket(ctx, *HeadBucketInput)` | `*Bucket` | Whether a bucket exists, and what the backend knows about it |
| `DeleteBucket(ctx, *DeleteBucketInput)` | `error` | Deletes an empty bucket; a missing one is `ErrBucketNotFound` |
| `ListBuckets(ctx, *ListBucketsInput)` | `*ListBucketsOutput` | One page of your buckets, by name; filter with `Prefix` |
| `PutObject(ctx, *PutObjectInput)` | `*ObjectInfo` | Streams the body; headers, metadata, length and a write condition are optional. A set `ContentLength` must match the body. Returns the ETag |
| `GetObject(ctx, *GetObjectInput)` | `*Object` | Body plus `ObjectInfo`; the caller closes `Body` |
| `HeadObject(ctx, *HeadObjectInput)` | `*ObjectInfo` | Size, content type, modification time, ETag, version, metadata and stored headers |
| `DeleteObject(ctx, *DeleteObjectInput)` | `*ObjectInfo` | Deleting a missing key succeeds |
| `ListObjects(ctx, *ListObjectsInput)` | `*ListObjectsOutput` | One page of a bucket's objects, by key, with `Prefix`, `Delimiter` and `StartAfter` |
| `PresignUploadURL(ctx, *PresignUploadURLInput)` | `*PresignURLResponse` | URL, method, and the headers the client must send |
| `PresignDownloadURL(ctx, *PresignDownloadURLInput)` | `*PresignURLResponse` | URL, method, and signed headers for a GET |

`GetObject` returns an open body the caller must close, and reports a missing
key as `storage.ErrKeyNotFound`. A `Range` such as `bytes=0-1023` reads part
of the object in both backends, and `Size` is then the length of that part.
The directory backend ignores a header that is not one valid byte range and
returns `storage.ErrInvalidRange` for one starting past the end. The S3
backend sends the header as given, so the result is S3's, and S3's `416`
comes back as `storage.ErrInvalidRange`.

<Code code={region(storage, 'download')} lang="go" />

The list methods return one page at a time, with the semantics of S3
ListObjectsV2 and ListBuckets. A page holds at most `MaxKeys` objects and
common prefixes together, or `MaxBuckets` buckets. The directory backend
defaults `MaxKeys` to 1000 and treats a larger value as 1000, and defaults
`MaxBuckets` to 10000. The S3 backend passes both through as given, so the
page size is S3's: S3 returns at most 1000 keys per page. To read the next page, pass the page's
`NextContinuationToken` back in the next input as `ContinuationToken`, and stop
when it is empty, which happens on the last page only (`ListObjects` also
reports `IsTruncated`). Each page's `Skipped` counts the entries the backend
could not read and left out, over the whole bucket; the directory backend
reports where they are to a handler given with `dir.WithSkipHandler`, and S3
never skips.
A `Delimiter` such as `/` groups keys under `CommonPrefixes`, the way S3
consoles show folders. Tokens are opaque and only valid for the backend that
issued them. The directory backend reads the metadata of every object in the
bucket on each `ListObjects` call, so a page costs time in proportion to the
bucket, not the page; it suits development and small buckets.

`PutObjectInput` embeds `ObjectHeaders` (content type, `Cache-Control`,
`Content-Disposition`, `Content-Encoding`, `Content-Language`, `Expires` and
metadata), and every header a write sets reads back on `ObjectInfo`. `Expires`
is text; the S3 backend accepts only an IMF-fixdate such as
`Wed, 21 Oct 2026 07:28:00 GMT`. Every object reports an `ETag`, unquoted;
compare ETags only for equality. `PutObjectInput` also embeds a
`WriteCondition`: `IfNoneMatch: "*"` writes only a key with no object, and
`IfMatch` only over the object with that ETag, so an update can be made
conditional on what was read.

Presigned URLs let the browser transfer bytes straight to S3, so large files
never pass through your server. Signing is local; no network call is made. A
nil or zero TTL signs 15 minutes; a TTL that is negative, under one second, or
over seven days is `storage.ErrInvalidTTL`.

On S3, `CreateBucket` creates the bucket in the client's region and sends the
location constraint S3 requires outside us-east-1 and `aws-global`. With no
configured region it uses the region the AWS SDK resolved. For a bucket you
already own it succeeds, and the returned `Bucket` may hold only the name.

## Config

Settings bind from the registered `gas.ConfigProvider`, under `storage`, so
they can come from environment variables or a config file.

| Key | Description |
|---|---|
| `storage.bucket` | Default bucket for inputs with a nil `Bucket`. Optional; must be a valid bucket name when set |
| `storage.region` | AWS region (s3). Empty uses the AWS SDK's default resolution |
| `storage.accessKeyID`, `storage.secretAccessKey`, `storage.sessionToken` | Static credentials (s3). Without `accessKeyID` the default credential chain applies |
| `storage.endpoint` | Custom endpoint for S3-compatible services (s3). Enables path-style addressing |

The providers have no start or close step: a provider is ready when its
constructor returns, and no request is sent at construction.

## Errors and testing

Classify failures with `errors.Is` against the sentinels in `storage`:

| Sentinel | Meaning |
|---|---|
| `ErrKeyNotFound` | `GetObject` of a missing key |
| `ErrNotFound` | `HeadObject` of a missing object; on S3 also a missing bucket, because HEAD responses carry no error code |
| `ErrBucketNotFound` | An object operation, `ListObjects`, `HeadBucket` or `DeleteBucket` on a missing bucket (S3 `HeadObject` excepted) |
| `ErrVersionNotFound` | S3 `GetObject` of a version that does not exist. S3 `HeadObject` reports it as `ErrNotFound`, and AWS may reject a malformed version ID with an error that carries no sentinel |
| `ErrBucketExists` | S3 `CreateBucket` of a name another account owns |
| `ErrBucketNotEmpty` | `DeleteBucket` of a bucket that holds objects |
| `ErrAccessDenied` | S3 `HeadBucket` or `DeleteBucket` answered 403 |
| `ErrPreconditionFailed` | A `PutObject` whose `WriteCondition` does not hold; nothing is written |
| `ErrInvalidCondition` | A `WriteCondition` that cannot be evaluated, such as an `IfNoneMatch` other than `*` |
| `ErrInvalidHeader` | An S3 `PutObject` or presigned upload whose `Expires` is not an IMF-fixdate |
| `ErrInvalidKey`, `ErrInvalidBucket`, `ErrInputRequired` | Input rejected before anything is sent |
| `ErrInvalidTTL` | A presign TTL out of bounds |
| `ErrInvalidLimit` | A `MaxKeys` under 1, or a `MaxBuckets` outside 1 to 10000 |
| `ErrInvalidContinuationToken` | A list token that is set but empty, or one the directory backend cannot decode. The directory backend cannot tell a well-formed token it did not issue, and resumes after the name it decodes to; S3 may reject a token it did not issue with an error that carries no sentinel |
| `ErrInvalidRange` | A `Range` whose first byte is at or past the end of the object, or `bytes=-0` |
| `ErrNotSupported` | A feature the backend does not implement, such as `Version` or `PartNumber` on the directory backend |
| `ErrContentLengthMismatch` | A `PutObject` whose body does not match its `ContentLength`; nothing is stored |
| `ErrInvalidOption` | A constructor given a nil option |
| `ErrNotInitialized` | A provider not built by its constructor |

The directory backend adds two sentinels of its own. `dir.ErrCorrupt` is an
object it cannot read, from `HeadObject` and `GetObject`; it never means the
object is missing, and a `PutObject` of the key replaces it.
`dir.ErrUnnamedBucket` is a bucket whose name record is missing or wrong;
`ListBuckets` leaves it out, and the skip handler receives an error wrapping
it.
