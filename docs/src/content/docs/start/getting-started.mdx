## Requirements

Go 1.26 or newer. Gas is pre-1.0, so minor versions may contain breaking
changes; see the [changelog](https://github.com/gasmod/gas/blob/main/CHANGELOG.md).

## Your first app

1. Install the core package.

   ```bash
   go get github.com/gasmod/gas
   ```

   <Code code={region(quickstart, 'app')} lang="go" title="main.go" />

3. Run it.

   ```bash
   go run .
   # listening on 0.0.0.0:8080
   ```

</Steps>

`gas.NewApp` builds a router, an event bus, and a DI container. `Run` initializes
every registered service, applies pending migrations, executes ready hooks,
starts the HTTP server, and blocks until a shutdown signal arrives. On shutdown
it closes services in reverse initialization order.

<Aside type="caution" title="Register under the interface, not the concrete type">
The container resolves dependencies by **exact type**. A service registered as
`*s3.Service` will not satisfy a dependency declared as `gas.StorageProvider`,
and startup fails with `no registration for gas.StorageProvider`. Register
infrastructure under its provider interface and your own services under their
concrete type. See [Services and DI](/gas/concepts/services-and-di/).
</Aside>
